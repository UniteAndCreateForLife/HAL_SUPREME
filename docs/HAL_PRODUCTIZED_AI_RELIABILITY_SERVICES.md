# HAL SUPREME — Productized AI Reliability Services

Public-safe service catalog for bounded technical engagements. These offers are designed to produce inspectable deliverables before any larger implementation commitment.

## 1. Agent Reliability Audit — starting at $600

For an existing agent, workflow, or AI feature that needs a concrete failure map.

**Deliverables**
- bounded failure taxonomy;
- reproducible test cases;
- retry, idempotency, and validation review;
- false-success and hallucination/evidence controls;
- observability recommendations;
- regression plan and non-secret evidence receipts.

**Typical first milestone:** one workflow or agent path, 3–5 business days.

## 2. MCP / Tool Integration Pilot — starting at $900

For a product or internal workflow that needs a controlled MCP/tool boundary before a larger build.

**Deliverables**
- bounded tool contract and schemas;
- authentication/authority boundary;
- error and failure handling;
- human approval gates for consequential writes;
- tests for representative read/write behavior;
- provider-neutral operating notes and handoff.

**Typical first milestone:** up to three bounded tools in a synthetic, sandbox, or approved test environment, 5–7 business days.

Production deployment, hosting, customer credentials, and broader API/backend work are scoped separately.

## 3. Evidence & Citation Validation Harness — starting at $800

For AI outputs that need explicit support, uncertainty handling, and repeatable checks.

**Deliverables**
- evidence contract;
- citation/source checks;
- unsupported-claim rejection rules;
- uncertainty and conflict handling;
- machine-readable receipts;
- reproducible evaluation cases and rerun notes.

**Typical first milestone:** one bounded use case, 5–7 business days.

## 4. Private / Local AI Architecture Review — starting at $600

For teams deciding what should run locally, what may egress, and how provider failure should be handled.

**Deliverables**
- local-first routing map;
- privacy and egress policy;
- provider abstraction review;
- fallback and failure behavior;
- validation checklist;
- deployment/runbook recommendations.

**Typical first milestone:** one architecture review, 3–5 business days.

## Engagement boundary

HAL SUPREME public evidence is self-operated engineering evidence unless a case study explicitly states otherwise. No external customer production deployment is implied by this catalog.

The preferred commercial entry point is a small paid milestone with explicit acceptance criteria, followed by a larger implementation only when the evidence supports it.
